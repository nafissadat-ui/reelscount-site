ReelsCount isn't tracking correctly

Make sure ReelsCount is enabled in Chrome and that you are using a supported short-form video page on YouTube, Instagram, Facebook or TikTok.

If the issue continues, reload the website and try again.

Found a bug?

When reporting a problem, please include the website where it happened, what you expected to happen, and what happened instead.
